# Agent guide

## Skills

Task guides live in `.agents/skills/<name>/SKILL.md`. Read the matching skill
before starting a task it covers:

- [`modelo-de-costos`](.agents/skills/modelo-de-costos/SKILL.md): the user asks
  to use "Modelo de costos" to estimate the cost of a house, house type or
  subtype (cost per house, UF/m²), or to decide between historic and estimated
  (BOM) quantities. Covers the tools, the process and the search for
  complementary SKUs before deciding.
